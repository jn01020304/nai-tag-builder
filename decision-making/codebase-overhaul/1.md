### R5: isVeryDark 휘도 계산 전환 `[internal]`

현황: theme.ts:157에서 5개 하드코딩 RGB 문자열과 `===` 비교. 화이트리스트에 없는 다크 테마에서 라이트 모드로 잘못 판정.

잠정 접근: RGB 문자열 파싱 후 `(0.299*R + 0.587*G + 0.114*B) / 255 < 0.5` 수식 적용.
```typescript
function isVeryDark(color: string): boolean {
  const m = color.match(/(\d+)\s*,\s*(\d+)\s*,\s*(\d+)/);
  if (!m) return true;
  return (0.299 * +m[1] + 0.587 * +m[2] + 0.114 * +m[3]) / 255 < 0.5;
}
```
